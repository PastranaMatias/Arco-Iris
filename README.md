# Arco-Iris
Arcoiris - Pintureria

La pinturería Arcoiris necesita tener un stock por marca y colores. Cuando un cliente quiere comprar, se busca en una carpeta las boletas de compra y se calcula el precio sobre el precio de costo. Lo usaría el sector de atención al publico.

Qué hace: Registra marcas, colores y precios. Se conoce que stock hay de cada marca y si falta algún color se hace el pedido para reposición.Se actualizan los precios en caso de incrementos y/o promociones y se tiene un stock acualizado.

Alcance mínimo comprometido: Aplicación de consola.
Metodología y lenguaje. Metodología XP, con iteraciones atados al calendario de clases y seguimiento en el tablero de Trello de la cátedra. Python 3.11, con uv y pytest.
